# Build presentations where the work already lives

An upgradeable Marp template for product and engineering teams

**August 2026**

---

## A small, stable interface

The generated workspace keeps shared infrastructure separate from deck content.

| Template-managed | User-owned |
| --- | --- |
| Themes and helper scripts | Slide Markdown |
| AI presentation guidance | Deck assets |
| Shared configuration | Per-deck CSS |

> Update the presentation system without overwriting the presentation.

---

## Designed for the repository workflow

1. Run `marpme new architecture-review`.
2. Edit the generated `deck.md`.
3. Preview with the official VS Code extension.
4. Export with Marp CLI when a PDF is needed.

```text
repo/
├── .marpme/       shared, versioned infrastructure
└── presentations/ user-owned decks and assets
```
